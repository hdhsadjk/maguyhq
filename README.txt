# GitHub Pages 優惠活動頁範本

1. 將 `index.html` 和 `assets/` 資料夾上傳到 GitHub 儲存庫根目錄。
2. 編輯 `index.html`，把 `https://example.com/replace-with-your-coupon-url` 換成你有權使用的實際優惠券網址。
3. GitHub 儲存庫進入 **Settings → Pages**。
4. 在 **Build and deployment** 選擇 **Deploy from a branch**，Branch 選 `main`，資料夾選 `/(root)`，按 **Save**。
5. 等待部署完成後，GitHub Pages 會顯示網站網址。

此範本包含「非官方網站」提示；若是品牌正式活動，請使用獲授權的素材與官方活動網址。
